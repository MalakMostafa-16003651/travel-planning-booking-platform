## Shared rules retained from the team agreement

- Keep one NestJS backend and shared Atlas database. This audit creates no M2 frontend or bonus implementation.
- Use _id with timestamps, camelCase domain IDs, userId for normal ownership, the agreed CreateXDto/UpdateXDto and NestJS service/controller names, and the /api prefix. Do not duplicate models, guards, searches, payment logic or enums.
- Current single enum exports were checked: UserRole, AccountStatus, BookingStatus, CabinClass, PaymentStatus, RefundStatus and PostStatus. BookingStatus includes COMPLETED/EXPIRED under GEN-11; RefundStatus currently uses PENDING/REFUNDED/FAILED per PAY-03. Do not reintroduce the original SUCCEEDED refund term in another module.
- Keep one platform booking/payment currency (USD). Current booking/provider monetary values use integer minor units; the payment adapter converts at its explicit major-unit boundary. Budget display currency/FX does not change booking prices.
- Agree shared schema/interface changes with affected owners before implementation and inform consumers. No new room/attraction/account-gate schema is adopted by this audit.
- Keep MONGODB_URI, JWT_SECRET, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, FXRATES_API_KEY and PORT as the agreed variable names. New names require agreement. Private .env files and credentials stay outside Git; .env.example is the public template.
- Work on named feature/fix/refactor/docs branches from current develop. Synchronize before work and PR, use meaningful commits, test valid/invalid/unauthorized/ownership/data changes, and submit related changes through reviewed PRs into develop.
- Never force push or implement directly on protected branches. Promote develop to main only as a reviewed stable milestone release. Local branch synchronization does not mean the feature sets are identical.
- Preserve one continuous AI record per student. Do not restore the removed AI_PROMPTS.txt or invent student understanding/review evidence. Each AI-using owner records their own important prompts and actual checks.
